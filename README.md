# MLN111_Ba_Quy_Luat

## Deploy to Render

This is a static HTML site. In Render, create a Static Site from this repository's `main` branch, leave Root Directory blank, use the build command `mkdir -p dist && cp MLN111_Ba_Quy_Luat.html dist/index.html`, and set Publish Directory to `dist`. No environment variables are required.

Alternatively, create a Blueprint and let Render read `render.yaml`.
